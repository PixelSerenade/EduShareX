# Edu Shared X

Edu Shared X is an academic notes sharing platform built with C#, ASP.NET Web Forms, and .NET Framework 4.7.2. It includes account registration and login, note uploads and browsing, note details, profiles, administration, and analytics pages.

## Project files

Open `EduX.sln` in Visual Studio with ASP.NET and .NET Framework 4.7.2 development tools installed.
