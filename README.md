# Edu Shared X

Edu Shared X is an academic notes sharing platform built with ASP.NET Web Forms and C# on .NET Framework 4.7.2. It includes account registration and login, note uploads and browsing, note details, profiles, administration, and analytics pages.

## Project files

Open `EduX.sln` in Visual Studio with ASP.NET and .NET Framework 4.7.2 development tools installed.

## Notes

- Uploaded profile photos and local Visual Studio/build output are excluded from Git.
- The current project is ASP.NET Web Forms on .NET Framework 4.7.2; it is not an ASP.NET Core MVC project.
